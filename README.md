# 💧 SAE Dev2 — Gestion des stocks d'eau

Application **JavaFX** de gestion des stocks pour le client fictif
**O-De-France** : suivi des eaux, stocks global et détaillé, clients.

![Java](https://img.shields.io/badge/Java-JavaFX-orange)

## Fonctionnalités

- Vues clients et stocks (MVC : vues + contrôleurs séparés)
- Tri automatique des listes
- Scène principale redimensionnable
- Boutons d'annulation et de retour à l'accueil

## Lancer

```bash
./gradlew run
